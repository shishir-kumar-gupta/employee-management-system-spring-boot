# Employee Management System

## Project Description
A REST API application built using
Java and Spring Boot.

## Technologies
- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Postman

## Features
- Add employees
- View employees
- Update employees
- Delete employees
- Search employees
- Validation and exception handling

## Database
MySQL

## How to Run
1. Clone the repository.
2. Create the MySQL database.
3. Configure application.properties.
4. Run the Maven application.
5. Test APIs using Postman.
